# Prediction-of-pneumonia-using-CNN
Pneumonia detection system using the deep learning appoarch

>>INTRODUCTION:

The identification of pneumonia developed into 
an essential research segment because advanced 
diagnostic systems help healthcare professionals.
 CNNs represent a deep learning framework 
suitable for image assessment which 
demonstrates strong performance in this domain.
 The technique demands CNN models to learn 
from extensive databases of chest X-ray images 
which contain information about their presence of
 pneumonia or absence. The “CNN” automatically 
detects important image features including lung 
opacities along with other disease indicators 
without requiring human intervention for 
selecting features. 
. The CNNs use their ability to 
identify complex patterns in order to achieve 
superior pneumonia diagnosis results beyond 
traditional methods.
Healthcare providers use CNN technology to 
decrease the duration of pneumonia diagnosis 
which lets doctors make prompt therapy choices. 
These automated systems united with clinical 
practice would allow improved patient care, 
particularly for locations with limited expert 
radiologist availability. Medical imaging has 
gained substantial advancement through the 
implementation of CNNs in pneumonia detection 
systems. 


>>ABSTRACT:

 A novel method has been developed 
for predicting pneumonia using convolutional neural 
networks through chest X-rays. The main advantage of 
predicting pneumonia accurately and quickly is that 
people's lives can be saved. In recent times, we have 
seen many people suffering from lung infections, and 
pneumonia is one reason for it. To predict the 
pneumonia. We can pursue a deep learning approach to
 determine whether a person has been affected by 
pneumonia. Next, we will use deep learning models 
such as CNN and VGG algorithms to train the images 
from a large data source, and each data block or raw 
data will be divided into a “training-set, testing-set 
and validation set”. For any model, we can provide 
70% of data for training, 15 % for test path, and 15% 
for valid path. This condition will be considered as a 
best fit and the chest x-rays will be trained 
perfectly to give the results or output more 
accurately. By using the pure architecture of 
convolutional neural networks the model will be 
trained perfectly and with test accuracy will be up to 
85% and the overall accuracy gained by the each and 
every epochs are 91.25%.
